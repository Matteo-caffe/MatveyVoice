# 0001. Локальное распознавание речи вместо облачного API

## Контекст

Пользователь хочет бесплатный аналог Aqua Voice и не хочет отдавать свой голос в чужое облако (манифест: R03, R06, R11i). Бесплатность и локальность он назвал сам.

## Решение

Речь распознаётся целиком на Маке, Whisper на устройстве. Единственное сетевое обращение — одноразовая загрузка модели. Аналитики и отчётов об ошибках наружу нет.

## Почему

- Облачные движки (OpenAI, Deepgram и т.п.) отвергнуты: они требуют ключа и платного тарифа, что противоречит «бесплатное целиком», и уносят голос с машины, что противоречит приватности.
- Компромисс «облако по умолчанию, локально по желанию» отвергнут: каждый облачный путь в коде — это обещание «ничего не уходит наружу», которое перестаёт быть правдой. Облако помечено в спецификации как «вне рамок».

## Последствия

- Нужно скачать модель: 250–630 МБ при первом запуске, плюс окно с прогрессом, повтор при обрыве и «прогрев» модели.
- Качество и скорость привязаны к железу: поддерживаются только Apple Silicon и macOS 14+, Intel-Маки отрезаны.
- Возможности Aqua, которым нужна большая языковая модель (правка текста нейросетью, контекст экрана), недоступны без нарушения этого решения.
- Известная слабость Whisper на тишине («галлюцинации») приходится закрывать своим фильтром.
- Автотесты не запускают настоящую модель; её проверяет только ручной прогон.
