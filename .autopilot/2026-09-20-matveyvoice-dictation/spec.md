# Спецификация: MatveyVoice — голосовой ввод в любом приложении macOS

## Задача

Печатать длинные сообщения руками медленно: в Telegram, WhatsApp, в чатах с нейросетями, в адресной строке Safari. Хочется просто сказать фразу и получить её текстом ровно там, где стоит курсор, — как это делает Aqua Voice. Но платить за такое приложение и отдавать свой голос в чужое облако пользователь не хочет: нужен бесплатный open source аналог, который всё делает на самом Маке.

## Решение

Маленькое приложение в строке меню. Зажал горячую клавишу — говоришь — отпустил: через секунду-две распознанный текст появляется в поле ввода того приложения, которое сейчас активно. Понимает русский и английский. Распознавание идёт целиком на Маке; после одноразовой загрузки модели интернет не нужен. Приложение бесплатное, лицензия MIT, исходники и готовая сборка лежат на GitHub.

Название — MatveyVoice. Код пишется с нуля; чужие названия, иконки и тексты Aqua Voice не используются.

## Решения по реализации

- **Платформа:** Swift + SwiftUI/AppKit, приложение-агент (`LSUIElement`), macOS 14+, Apple Silicon. Почему: нативное приложение в строке меню легче и надёжнее с горячими клавишами и вставкой; Whisper на Neural Engine/GPU только так работает быстро.
- **Распознавание:** WhisperKit (MIT, Swift Package, модели Whisper в CoreML, лицензия моделей MIT). Почему: единственный зрелый Swift-путь к локальному Whisper на Apple Silicon без C-сборок; понимает русский. Модели: `small` (быстрая, примерно 250 МБ) и `large-v3-turbo` (точная, примерно 630 МБ, по умолчанию). Качается один раз в папку приложения в Application Support.
- **Запись:** AVAudioEngine, моно 16 кГц, буфер в памяти; на диск звук не пишется. Почему: голос не должен оставаться следов, а Whisper всё равно ждёт 16 кГц.
- **Пакетный, а не потоковый режим:** текст появляется после отпускания клавиши. Почему: с turbo-моделью на Apple Silicon это секунда-две на фразу, а потоковая вставка ломает текст в приложениях, где нельзя «переписывать» уже вставленное.
- **Вставка:** через буфер обмена и синтетическое нажатие ⌘V; прежнее содержимое буфера сохраняется целиком и возвращается сразу после вставки. Почему: это единственный способ, который одинаково работает в Telegram, WhatsApp, Safari и веб-полях; доступность через API у половины приложений сломана.
- **Горячая клавиша:** слежение за клавишами-модификаторами через системный перехват событий. Какие именно разрешения потребует система на конкретной версии macOS, исполнитель определяет на месте и показывает только нужные в чек-листе.
- **Фильтр тишины:** до распознавания проверяется громкость записи; после — отбрасываются известные «галлюцинации» Whisper на тишине (вроде «Субтитры сделал…», «Продолжение следует…», «Thanks for watching») и результаты, где модель сама пометила отсутствие речи. Почему: без этого на молчании в чат уходит мусор — известная слабость Whisper.
- **Слова-паразиты:** простой список «э / эм / ээ / uh / um» как отдельные слова, регистронезависимо; без нейросетевой правки текста. Почему: правило предсказуемо и не переписывает смысл.
- **Словарь:** слова передаются модели как подсказка (prompt) перед распознаванием. Почему: единственный честный способ повлиять на написание без постобработки.
- **Хранение:** настройки в UserDefaults; никаких баз, аккаунтов и логов с текстом диктовки. Последний результат живёт только в памяти до выхода из приложения.
- **Сеть:** только загрузка модели с Hugging Face. Почему: так устроен WhisperKit; всё остальное офлайн.
- **Сборка:** Swift Package (библиотека с логикой + исполняемый файл) и скрипты: `build-app.sh` собирает `.app` с ad-hoc подписью, `make-dmg.sh` делает `.dmg`. Почему: не нужен Xcode-проект и платный аккаунт; сборка воспроизводима одной командой.
- **Лицензия:** MIT. Почему: самая простая и совместимая с зависимостями; пользователь лицензию не назвал — это принято за него (ASSUMPTION) и указано в отчёте.
- **Интерфейс:** строки хранятся в каталоге локализации, русский и английский.

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| `Settings` | настройки пользователя (клавиша, режим, язык, модель, словарь, слова-паразиты, автозапуск) | `AppSettings` — наблюдаемая структура: `hotkey`, `triggerMode` (`hold`/`toggle`), `language` (`auto`/`ru`/`en`), `modelID`, `dictionary: [String]`, `removeFillers: Bool`, `launchAtLogin: Bool` | способ хранения (UserDefaults) |
| `HotkeyMonitor` | слежение за клавишей запуска | `start(hotkey: Hotkey, onPress: () -> Void, onRelease: () -> Void, onCancel: () -> Void)`, `stop()`, `isAvailable: Bool` | системный перехват событий, отбрасывание сочетаний с другими клавишами |
| `AudioRecorder` | запись голоса | `start() throws`, `stop() -> RecordedAudio` (`samples: [Float]` 16 кГц моно, `duration`), `levels: AsyncStream<Float>` | AVAudioEngine, преобразование частоты, лимит 5 минут |
| `Transcriber` (протокол) | распознавание | `state: ModelState` (`notInstalled`/`downloading(progress)`/`preparing`/`ready`/`failed(reason)`), `prepare(modelID:) async`, `transcribe(_ audio: RecordedAudio, language: Language, hints: [String]) async throws -> Transcription?` (`nil` — речи нет), `cancelPrepare()` | WhisperKit, загрузка, прогрев, фильтр тишины и галлюцинаций |
| `TextPostProcessor` | правка результата | `process(_ text: String, removeFillers: Bool) -> String` (чистая функция) | список паразитов, обрезка пробелов |
| `TextInserter` (протокол) | вставка текста в активное приложение | `insert(_ text: String) async throws -> InsertResult` (`inserted`/`copiedOnly(reason)`) | буфер обмена, синтетический ⌘V, возврат буфера |
| `Permissions` | статус и запрос разрешений | `status: PermissionsStatus` (микрофон, доступ для вставки/слежения), `request(_:)`, `openSettings(_:)`, поток изменений | конкретные API macOS |
| `DictationController` | сценарий диктовки | `state: DictationState` (`idle`/`recording`/`transcribing`/`inserting`/`message(text)`), `lastResult: String?`, `handlePress()`, `handleRelease()`, `handleCancel()` | конечный автомат, лимиты, порядок вызовов, повторное нажатие в процессе |
| `UI` | меню, плашка, настройки, чек-лист первого запуска | только чтение `DictationController`, `Settings`, `Permissions`, `Transcriber.state` | вёрстка |

**Шов для тестов один — `DictationController`.** Ему подставляются `Transcriber` и `TextInserter` (и запись) через протоколы; поведение проверяется по состояниям и вызовам. Чистая функция `TextPostProcessor` проверяется напрямую (это не шов, а функция без зависимостей). Настоящая модель Whisper в автотестах не запускается (сотни МБ); её проверяет ручной прогон на реальном звуке.
