## Что должно заработать

Приложение оживает целиком: иконка в строке меню со статусами и меню («Настройки», «Скопировать последнюю диктовку», статус модели и разрешений, «Выйти»), плашка у нижнего края экрана без захвата фокуса, окно настроек (клавиша, режим, язык, модель, словарь, слова-паразиты, автозапуск), окно первого запуска с чек-листом разрешений и прогрессом загрузки. Настоящие модули подключены к `DictationController`.

## Критерии приёмки

- [ ] Меню строки меню показывает состояние (готов / запись / обработка / нет модели / нет разрешений), пункты «Настройки…», «Скопировать последнюю диктовку», «Выйти»
- [ ] Плашка: `NSPanel` без активации, уровень звука во время записи, сообщения из `DictationState.message`; активное приложение и поле ввода остаются прежними
- [ ] Настройки: клавиша (с подсказкой про Fn), режим удержание/переключатель, язык (с оговоркой про смесь языков), модель, словарь, слова-паразиты, «Запускать при входе»; всё сохраняется через `AppSettings`
- [ ] Первый запуск: чек-лист «микрофон / доступ для клавиши и вставки / модель» с живым статусом, кнопками «Открыть настройки» и «Повторить», полоса прогресса загрузки с размером, показ причины сбоя
- [ ] Отзыв разрешения во время работы виден в меню, диктовка не притворяется рабочей
- [ ] Интерфейс на русском и английском по языку системы
- [ ] `swift build` и `swift test` зелёные; `scripts/build-app.sh` даёт запускающееся приложение
- [ ] Что проверить руками по живому списку (Telegram, WhatsApp, Safari, ChatGPT/Claude, Заметки, Сообщения, Почта, Терминал) — записано в отчёт таска как чек-лист; автоматически это проверить нельзя, не выдавать за проверенное
