## Что должно заработать

Ограниченный набор исправлений из списка отложенных замечаний, которые нельзя оставлять: приватность буфера обмена, надёжность вставки, случайные нажатия, гонка при лимите записи и единый способ доступа к строкам. Новых возможностей нет.

## Критерии приёмки

- [ ] Текст диктовки помечается в общем буфере как временный/скрытый (`org.nspasteboard.TransientType`, `org.nspasteboard.ConcealedType`), чтобы менеджеры буфера обмена его не сохраняли; тест на приватном NSPasteboard проверяет наличие пометки и то, что после возврата буфера пометки нет.
- [ ] Возврат прежнего буфера не происходит раньше паузы даже при отмене задачи (отмена не приводит к немедленному восстановлению до вставки); тест.
- [ ] Клавиша ⌘V определяется по текущей раскладке (или явно запасной путь), не привязана к коду 9 без оговорки.
- [ ] `HotkeyStateMachine`: если другие клавиши/модификаторы уже удерживались в момент нажатия триггера, `press` не выдаётся; тесты. Классификатор проверен тестом для всех четырёх клавиш (rightOption, rightCommand, rightControl, fn).
- [ ] `HotkeyMonitor` останавливает tap в `deinit`.
- [ ] `AudioRecorder`: колбэк лимита останавливает только тот engine, что вызвал лимит (нет гонки со `stop()`/новым `start()`); лимит в проекте считается в одном месте: либо `AudioRecorder.onLimitReached` подключён и используется контроллером/`AppModel`, а собственный таймер контроллера убран, либо неиспользуемое удалено — без изменения поведения для пользователя (сообщение о лимите остаётся).
- [ ] Строки: `DictationController` и `TranscriptionErrors` берут строки через `String(localized:table:bundle:)` единообразно с остальным проектом, английский дубль в коде убран; поведение в приложении то же.
- [ ] `StatusLogic` вынесена в `MatveyVoiceCore` с тестами (отзыв микрофона/доступа, порядок приоритетов, границы прогресса, `needsChecklist`); порог 0,3 с — одна публичная константа, которой пользуются и контроллер, и плашка; `setupCompleted` переехал в `AppSettings`. Правка `Package.swift` разрешена только если она нужна для тестов исполняемой цели — иначе не трогать.
- [ ] `swift test -Xswiftc -plugin-path -Xswiftc /Library/Developer/CommandLineTools/usr/lib/swift/host/plugins/testing` зелёный (было 49), `scripts/build-app.sh` собирает, приложение стартует.
