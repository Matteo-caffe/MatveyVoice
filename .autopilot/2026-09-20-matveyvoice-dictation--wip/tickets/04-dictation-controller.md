## Что должно заработать

`DictationController` ведёт весь цикл «нажал → записал → распознал → вставил» и не знает ни про WhisperKit, ни про буфер обмена: он работает через протоколы из общих типов. Единственный шов для тестов проекта.

## Критерии приёмки

- [ ] Состояния `idle → recording → transcribing → inserting → idle`, любое сообщение пользователю — `message(text)` на короткое время и обратно в `idle`
- [ ] `hold`: press начинает, release завершает; `toggle`: первое нажатие начинает, второе завершает
- [ ] Запись короче 0,3 с отбрасывается молча; `handleCancel` отбрасывает запись без следа
- [ ] Нажатие во время `transcribing`/`inserting` игнорируется без потерь и дублей; запись, дошедшая до лимита, всё равно распознаётся
- [ ] Тишина (`nil` от транскрайбера) — сообщение «Не расслышал», ничего не вставляется; ошибка распознавания — сообщение с причиной, контроллер снова `idle`
- [ ] `copiedOnly` от вставки — сообщение «Нужен доступ»; `lastResult` хранит последний результат в памяти
- [ ] Пока модель не `ready`, начало записи не происходит и говорится почему
- [ ] Тесты на Swift Testing через подставные `AudioRecording`, `Transcribing`, `TextInserting`: полный путь, отмена, короткое нажатие, тишина, ошибка, повторное нажатие в процессе, режим переключателя, лимит
