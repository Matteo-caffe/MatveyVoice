# MatveyVoice

[English version](README.md)

Бесплатная, открытая и полностью локальная диктовка для macOS. Удерживаете клавишу, говорите, отпускаете: текст вставляется в то приложение, в котором вы работаете. Распознавание речи идёт на вашем Mac через Whisper; голос никуда не уходит.

Вдохновлено идеей Aqua Voice. MatveyVoice это самостоятельный проект: он не связан с Aqua Voice и не использует его код, логотипы и другие материалы.

## Требования и ограничения

- macOS 14 или новее, Apple Silicon (M1 и новее). Intel не поддерживается.
- Языки: автоопределение, русский или English. Смесь языков в одной фразе не гарантируется.
- Приложение подписано ad-hoc и не нотаризовано (см. «Первый запуск»).

## Установка

### Из .dmg

1. Скачайте `MatveyVoice.dmg` на странице [Releases](https://github.com/Matteo-caffe/MatveyVoice/releases).
2. Откройте образ и перетащите MatveyVoice на ярлык «Программы».
3. Первый запуск заблокирует Gatekeeper, потому что приложение не нотаризовано. На macOS 15 и новее один раз попробуйте открыть приложение, затем зайдите в Системные настройки > Конфиденциальность и безопасность, прокрутите вниз до сообщения про MatveyVoice и нажмите «Всё равно открыть». На macOS 14 нажмите правой кнопкой по приложению и выберите «Открыть». На любой версии можно и так:

   ```
   xattr -dr com.apple.quarantine /Applications/MatveyVoice.app
   ```

### Сборка из исходников

Нужен Swift (достаточно Command Line Tools, Xcode не нужен).

```
git clone https://github.com/Matteo-caffe/MatveyVoice.git
cd MatveyVoice
scripts/build-app.sh      # собирает build/MatveyVoice.app (arm64)
scripts/make-dmg.sh       # по желанию: build/MatveyVoice.dmg
open build/MatveyVoice.app
```

`scripts/make-icon.sh` заново рисует `Resources/AppIcon.icns` из кода.

Заметка для машин только с Command Line Tools: Swift Testing может не собираться с ошибкой «plugin for module TestingMacros not found». Запускайте тесты так:

```
swift test -Xswiftc -plugin-path -Xswiftc /Library/Developer/CommandLineTools/usr/lib/swift/host/plugins/testing
```

## Первый запуск и разрешения

MatveyVoice живёт в строке меню. При первом запуске он проведёт вас по шагам:

- **Микрофон**: чтобы записывать голос.
- **Универсальный доступ**: чтобы следить за клавишей запуска и вставлять текст через ⌘V.
- **Загрузка модели**: один раз, см. ниже.

Приложение подписано ad-hoc, поэтому macOS считает каждую пересборку новым приложением: после пересборки из исходников разрешения нужно выдать заново.

## Как пользоваться

- По умолчанию: удерживайте **правый ⌥**, говорите, отпустите. В настройках можно выбрать правый ⌘, правый ⌃ или Fn.
- Режим «переключатель» (нажать, чтобы начать, ещё раз, чтобы закончить) включается в настройках.
- Нажатие клавиши запуска вместе с другой клавишей отменяет запись.
- Текст вставляется через буфер обмена, после чего прежнее содержимое буфера возвращается. Enter за вас не нажимается.
- Язык: авто, русский или English.

## Модели

| Модель | Размер | Заметки |
|---|---|---|
| small | ~250 МБ | быстрее, легче |
| large-v3-turbo | ~630 МБ | по умолчанию, точнее |

Модель скачивается один раз с Hugging Face в `~/Library/Application Support/MatveyVoice/Models`. Токенизатор WhisperKit тоже берёт оттуда же. После этого интернет не нужен.

## Конфиденциальность

Ничего не отправляется наружу: нет аналитики, телеметрии и аккаунтов. Единственный сетевой трафик это разовая загрузка модели. Звук и продиктованный текст на диск не сохраняются.
