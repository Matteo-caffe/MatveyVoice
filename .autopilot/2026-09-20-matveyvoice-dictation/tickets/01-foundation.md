## Что должно заработать

Проект собирается и запускается: `swift build` проходит, `scripts/build-app.sh` даёт `build/MatveyVoice.app`, который при запуске живёт только иконкой в строке меню (без Dock), со статичным меню «Выйти». Вторая копия не запускается. Все общие типы и протоколы из `interfaces.md` существуют и компилируются, `AppSettings` хранит настройки и переживает перезапуск. Подключён WhisperKit, пакет зависимостей разрешается.

## Критерии приёмки

- [ ] `swift build` проходит с зависимостью WhisperKit, других внешних зависимостей нет
- [ ] `scripts/build-app.sh` собирает `build/MatveyVoice.app` с `LSUIElement`, минимумом macOS 14.0, ad-hoc подписью; приложение стартует
- [ ] Повторный запуск при работающей копии не создаёт вторую иконку
- [ ] Пункт «Выйти» завершает приложение
- [ ] Все типы и протоколы из «Границ» существуют с указанными формами; `AppSettings` имеет значения по умолчанию из спецификации (правый ⌥, удержание, язык авто, модель large-v3-turbo, паразиты вкл, автозапуск выкл, словарь пуст) и сохраняется между запусками
- [ ] Есть тест на `AppSettings` (значения по умолчанию и сохранение) на Swift Testing; `swift test` зелёный
- [ ] Механизм строк: `String(localized:table:bundle:)` работает для таблицы `UI` на en и ru (по одной строке для меню «Выйти»)
