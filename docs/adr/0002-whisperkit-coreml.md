# 0002. WhisperKit (CoreML) как движок Whisper

## Контекст

Решено распознавать локально (ADR 0001). Нужен Whisper на Apple Silicon, понимающий русский, в нативном Swift-приложении.

## Решение

Используется WhisperKit: Swift Package с моделями Whisper в CoreML. Две модели: `small` (быстрая, около 250 МБ) и `large-v3-turbo` (точная, около 630 МБ, по умолчанию). Модели лежат в Application Support.

## Почему

- Путь через C/C++-реализации Whisper отвергнут: он тянет C-сборки в проект, который задуман как чистый Swift Package без Xcode-проекта (ADR 0005). WhisperKit в спецификации назван единственным зрелым Swift-путём без C-сборок.
- Запуск на Neural Engine/GPU через CoreML даёт секунду-две на фразу, что нужно для пакетного режима (ADR 0003).
- Лицензии пакета и моделей — MIT, что совместимо с лицензией проекта.

## Последствия

- Загрузка идёт с Hugging Face, потому что так устроен WhisperKit; это и есть единственное сетевое обращение.
- Проект зависит от одного стороннего пакета: его API, поддержка новых версий macOS и формат моделей вне нашего контроля.
- Смена движка потом стоит дорого. Граница — протокол `Transcriber`; всё специфичное для WhisperKit (загрузка, прогрев, фильтр галлюцинаций) сидит за ней, но подсказки словаря и состояния модели уже подогнаны под его возможности.
- Первый запуск модели медленный (прогрев), об этом приходится говорить пользователю.
