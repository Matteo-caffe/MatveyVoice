# 0003. Пакетное распознавание после отпускания клавиши

## Контекст

Диктовка идёт по схеме «зажал, сказал, отпустил». С turbo-моделью на Apple Silicon фраза распознаётся за секунду-две.

## Решение

Звук копится в памяти, пока клавиша зажата. После отпускания вся запись распознаётся целиком, и текст вставляется один раз.

## Почему

- Потоковая вставка по мере речи отвергнута: текст в поле пришлось бы переписывать по мере уточнения гипотез модели, а во многих приложениях уже вставленное переписать нельзя. Результат — испорченный текст.
- Задержка в секунду-две при пакетном режиме приемлема для коротких фраз, поэтому выигрыш потока не оправдывает сложность.

## Последствия

- Пока не отпустишь клавишу, текста нет: обратной связи «на лету» нет, только плашка с уровнем звука.
- Нужен лимит записи (5 минут) и состояние «Обрабатываю»; повторное нажатие во время распознавания обрабатывается отдельно.
- Длинная запись растёт в памяти, а время распознавания растёт вместе с ней.
- Потоковый режим в спецификации отложен, а не закрыт. Добавить его позже — значит менять и распознавание, и вставку.
